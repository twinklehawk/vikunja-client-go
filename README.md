# vikunja-client-go
Vikunja API client in Go

## Building
`go build`

## Formatting
`go fmt ./...`

## Testing
`go test ./...`

### Mocking
Mocks are created by the [mockgen](https://github.com/uber-go/mock) utility.
Commands for generating mocks are embedded in the file containing the interface to mock as `go:generate` commands.
Mocks can be regenerated by running `go generate ./...`.
